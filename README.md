## 🚀 How to Use a Template

1. Browse the index above and pick your template
2. Read the template's `README.md` for prerequisites
3. Copy the template files into your project
4. Fill in your environment variables (check `.env.example`)
5. Deploy 🚀

---

## 🍽️ What's on the Menu? 🍽️

A collection of ready-to-use templates for AWS deployments, GitHub Actions workflows, and Infrastructure as Code — built from real-world experience so you can stop Googling the same thing twice.

Each template comes with:
- ✅ A working, copy-paste-ready template
- ✅ A clear README explaining what it does and how to use it
- ✅ Required environment variables and secrets documented
- ✅ An architecture diagram where applicable
